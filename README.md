# 💸 로또

## 로또 구현 기능 목록

### 입력 기능 구현

* [x] 로또 구입 금액을 입력받는다. (구입 금액은 1,000원 단위로 입력 받아야 한다.)
* [x] 당첨 번호를 입력받는다.
* [x] 보너스 번호를 입력받는다.

### 입력한 구입 금액, 보너스 번호 숫자 변환 기능 구현

* [x] 입력받은 구입 금액, 보너스 번호를 숫자로 변환하여 반환한다.
    * [x] 입력값이 비어있으면 `IllegalArgumentException`을 발생시키고, 다시 입력 받는다.
    * [x] 구입 금액과 보너스 번호가 숫자가 아니면 `IllegalArgumentException`을 발생시키고, 다시 입력 받는다.

### 입력한 당첨 번호 저장 기능 구현

* [x] 문자열을 쉼표(,) 기준으로 구분하여 숫자 형태로 저장 후 반환한다.
    * [x] 입력값이 비어있으면 `IllegalArgumentException`을 발생시키고, 다시 입력 받는다.
    * [x] 당첨 번호가 6자리가 아닌 경우 `IllegalArgumentException`을 발생시키고, 다시 입력 받는다.

### 구입 금액에 따른 티켓 생성 기능 구현

* [x] 입력 받은 구입 금액을 1,000원 단위로 나누어 티켓 개수를 반환한다.
    * [x] 구입 금액이 1,000원으로 나누어 떨어지지 않으면 `IllegalArgumentException`을 발생시키고, 다시 입력 받는다.

### 로또 생성 기능 구현

* [x] 6개의 로또 번호를 생성해 저장한다.
    * [x] 로또 번호가 6자리가 아닌 경우 `IllegalArgumentException`이 발생한다.
    * [x] 로또 번호가 1 ~ 45 이내의 숫자가 아닌 경우 `IllegalArgumentException`이 발생한다.
    * [x] 로또 번호에 중복된 숫자가 존재하는 경우 `IllegalArgumentException`이 발생한다.
* [x] 생성된 로또 번호를 반환한다.

### 티켓 개수에 따른 로또 생성 기능 구현

* [x] 입력 받은 티켓 장수만큼 로또 번호를 생성하여 반환한다.

### 당첨 번호 & 보너스 번호 저장 기능 구현

* [x] 당첨 번호와 보너스 번호를 함께 저장한다.
    * [x] 당첨 번호와 보너스 번호가 1 ~ 45 이내의 숫자가 아닌 경우 `IllegalArgumentException`을 발생시키고, 다시 입력 받는다.
    * [x] 당첨 번호 내에 중복된 번호가 존재하면 `IllegalArgumentException`을 발생시키고, 다시 입력 받는다.
    * [] 보너스 번호가 당첨 번호에 존재하는 숫자와 중복 되는 경우 `IllegalArgumentException`을 발생시키고, 다시 입력 받는다.
* [] 당첨 번호와 발행한 로또 번호가 몇 개 일치하는지 카운트한 후 반환한다.
* [] 보너스 번호가 발행한 로또 번호에 존재하는지 여부를 반환한다.

### 당첨 정보 저장 기능 구현

* [] 등수 별 당첨 개수, 보너스 볼 여부, 우승 상금, 당첨 메세지를 저장한다.
* [] 우승 상금과 당첨 메세지를 반환한다.
* [] 당첨 번호와 보너스 번호를 등수 별 당첨 개수, 보너스 볼 여부와 비교 후 그에 맞는 등수를 반환한다.

### 당첨 등수 반환 기능 구현

* [] 발행한 로또와 당첨 번호를 비교하여 일치 개수를 반환한다.
* [] 발행한 로또에 보너스 번호가 존재하는지 여부를 반환한다.
* [] 위의 결과를 토대로 나온 당첨 등수를 반환한다.

### 로또 결과 반환 기능 구현

* [] 구매한 로또가 둥수 별로 몇 개씩 당첨되었는지 저장한다.
* [] 당첨된 등수별로 상금을 구해 총 상금을 반환한다.
* [] 구입 금액과 최종 상금을 통해 수익률을 구한다.

### 출력 기능 구현

* [] 구매한 모든 로또를 오름차순으로 나열하여 출력한다.
* [] 몇 개의 로또에 당첨되었는지 당첨 통계를 출력한다.
* [] 총 수익률을 출력한다.(수익률은 소수점 첫째 자리까지만 출력한다.)
